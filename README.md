# CityHub — расширение для SillyTavern

Мобильное приложение жителей обычного современного города: студентов и школьников, взрослых и родителей, пенсионеров, людей любых профессий — от уборщика до министра. Жители разные: добрые и не очень.

Работает отдельно от UniHub — их можно установить одновременно.

## Установка
Как UniHub: файлы из архива — в корень отдельного репозитория на GitHub, затем в SillyTavern «Расширения → Install extension» по ссылке. Открывается через волшебную палочку.

## Вход
Имя, пол, возраст (18–22, 23–27, 28–34, 35–44, 45–54, 55–64, 65+), профессия (больше 80 вариантов по группам или своя). Для студентов — ещё факультет и курс.

## Главное
- Лента, авторитет, чаты, знакомства (свидания и друзья: пол, возраст, подробные анкеты — только 18+).
- Кабинет: распорядок по профессии (смены, учёба, прогулки, встречи и брони), кнопки «Отправиться…», задания дня и поручения, рейтинг законопослушности, повседневная помощь.
- Правонарушения берутся из истории: CityHub следит, что делает ваш персонаж. Последствия — штрафы, вызовы в полицию, ограничение свободы.
- Город: мероприятия, клубы по интересам, бронирование (помещения и склад, отель, квартира через хозяина, базы отдыха, авиабилеты, фотостудия, каршеринг, одежда, экскурсии, столики), обращения (благоустройство, сантехник, письмо президенту, своя тема).
- Доставка еды и продуктов, маркет, кошелёк с зарплатой по профессии, встречи, время истории — как в UniHub.
