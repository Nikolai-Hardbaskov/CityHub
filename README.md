# CityHub — расширение для SillyTavern

Мобильное приложение жителей обычного современного города: студентов и школьников, взрослых и родителей, пенсионеров, людей любых профессий — от уборщика до министра. Жители разные: добрые и не очень.

Работает отдельно от UniHub — их можно установить одновременно.

Текущая версия: **1.0.16**.

## Установка
Как UniHub: файлы из архива — в корень отдельного репозитория на GitHub, затем в SillyTavern «Расширения → Install extension» по ссылке. Открывается через волшебную палочку.

## Вход
Имя, пол, возраст (18–22, 23–27, 28–34, 35–44, 45–54, 55–64, 65+), профессия (больше 80 вариантов по группам или своя). Для студентов — ещё факультет и курс.

## Синхронизация с основным чатом

### Вступление и реролл первого ответа

CityHub можно включить до первого сообщения, даже если вступление в карточке персонажа пустое. Пока вы выбираете его и ещё не ответили на него в основном чате, модель получает профиль и ваши действия в приложении: переписки, заказы, договорённости о встречах. Автоматические задания и зацепки, распорядок, часы, уведомления и выводы об отношениях из предыдущего варианта вступления в этот запрос не передаются. Проверка правонарушений также ждёт начала игры.

Задания дня создаются после вашего ответа на выбранное вступление. Если старая версия уже создала задания до начала истории, они временно скрыты и обновляются после выбора вступления. Устаревший ответ генератора заданий от изменённой сцены или другого чата отбрасывается. Это устраняет закрепление вступления через CityHub; карточка, лор, другие расширения и настройки модели по-прежнему влияют на различие рероллов.

### Время и отношения

Оценка отношений до выбора вступления предварительная: она не создаёт ссоры, примирения, уведомления о паре и не меняет отметку пары в профиле. После вашего ответа выбранная история оценивается заново. Старые автоматические ссоры из отвергнутого вступления удаляются без ложного «недавно помирились»; явные действия в переписке CityHub сохраняются. При пересчёте текущей ссоры обновляется её причина по актуальной истории.

Связь работает автоматически, пока открыта вкладка SillyTavern, даже если окно CityHub закрыто. Новые сообщения, правки, смена варианта ответа, удаление сообщений и переключение чата обновляют контекст. Отношения с персонажем и знакомыми из истории пересчитываются после изменений, без ожидания шести сообщений и открытия переписки. Переписки CityHub передаются рассказчику при включённых настройках «Передавать статус жителя ИИ» и «Передавать переписку CityHub в основной чат»; личные сообщения известны только их участникам.

Horae читается через её публичный API `window.Horae.getLatestState()`; для старых версий используются `horae_meta.timestamp` и теги `<horae>`. Поля `story_date` и `story_time` соединяются, даже если дата была указана много сообщений назад. Поддерживаются обычные даты с годом, даты `М/Д`, русские даты с точками и месяцы словами, числовые китайские даты и время `ЧЧ:ММ`. Нестандартные календари и время вроде «после полудня» не гарантируют точной синхронизации.

Время обновляется по событиям Horae/чата и резервно каждые пять секунд. Без доступного времени Horae приоритет получают явные заголовки «Дата: …», «Время: …» текущей сцены; затем время оценивает ИИ либо применяется шаг за ответ. При загрузке уже существующего чата ИИ может восстановить явно указанное текущее время сцены, без добавления лишних минут. Синхронизация может исправить дату и перевести часы назад.

Если Horae отсутствует и время невозможно определить из чата, CityHub придумывает начальное игровое время с учётом сцены. При недоступном или отключённом ИИ время выбирается локально: например, 09:00 для неопределённой сцены, 19:00 для вечера, 23:00 для ночи. Известная дата из заголовка чата сохраняется; если дата неизвестна, используется текущая дата начальных часов. Источник отмечается как «придуманное время». Значение сохраняется отдельно для каждого чата и не выбирается заново при опросе или перезагрузке. Дальше часы движутся по истории/шагу за ответ; появившееся точное время чата или Horae заменяет придуманное. Ручное время не заменяется выдумкой.

Повторное событие не добавляет время повторно, а правка последнего ответа заменяет его шаг, если часы не менялись вручную. Удаление последних ответов отменяет их шаги времени; уже наступившие последствия (доставка, штрафы, дедлайны) автоматически не отменяются. Игровые часы не идут по реальному времени, пока история стоит. Для синхронизации выберите в CityHub «Время истории» и включите «Брать время из Horae»; для оценки текста без Horae — «ИИ определяет время по тексту».

Фоновые оценки отношений и времени используют выбранную модель и расходуют её запросы/токены. Они выполняются по изменениям истории, а не на каждом резервном опросе. При переключении чата или изменении истории устаревшие результаты не применяются. Оценки ИИ зависят от качества модели и ограниченного контекста; синхронизация не гарантирует безошибочное понимание всех событий.

## Комментарии и задания

Задания на комментарии и ответы проверяются по всем условиям: нужный пост, адресат, ветка ответа и тема. Ответ про мотоциклы не выполняет задание обсудить распродажу, даже если это комментарии под одним постом. Новое задание может быть связано с точным постом или комментарием; ответы сохраняют id родительского комментария. Для тематической проверки используется подключённая модель. Без подтверждения и фрагмента текста, на который опирается проверка, прогресс не добавляется. Один комментарий засчитывается в одном задании не более одного раза. Уже полученные награды автоматически не отменяются.

В ответах `@Имя` выводится один раз. Повторные собачки и повторное обращение в начале текста удаляются при отображении, в том числе у старых комментариев; другие упоминания внутри сообщения сохраняются.

## Главное
- Лента, авторитет, чаты, знакомства (свидания и друзья: пол, возраст, подробные анкеты — только 18+).
- Кабинет: распорядок по профессии (смены, учёба, прогулки, встречи и брони), кнопки «Отправиться…», задания дня и поручения, рейтинг законопослушности, повседневная помощь.
- Правонарушения берутся из истории: CityHub следит, что делает ваш персонаж. Последствия — штрафы, вызовы в полицию, ограничение свободы.
- Город: мероприятия, клубы по интересам, бронирование (помещения и склад, отель, квартира через хозяина, базы отдыха, авиабилеты, фотостудия, каршеринг, одежда, экскурсии, столики), обращения (благоустройство, сантехник, письмо президенту, своя тема).
- Доставка еды и продуктов, маркет, кошелёк с зарплатой по профессии, встречи, время истории — как в UniHub.
